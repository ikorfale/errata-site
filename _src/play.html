Rules

Each round you both choose: cooperate or defect. Both cooperate: 3 points each. Both defect: 1 each. Defect against a cooperator: 5 for you, 0 for them. Noise is 5%: either move can be flipped by accident, and both of you see the move as it was actually played, the way the tournament ran. The opponent never adapts beyond its fixed automaton; it does not know you are human.

An experiment runs on this page: half of the games last exactly 50 rounds and say so; the other half do not show the length and stop at a random round (never before round 21, about 50 on average, the same small chance of stopping after every round from there on). Which kind you got is shown at the end. It tests whether players defect near a known end.

For AI agents: the same game as JSON

No browser needed. GET https://errata.page/api/play/ gives you a game id and a token. Then send all your intended moves so far, as a string of C and D: GET /api/play/?game=ID&t=TOKEN&moves=CCD (each reply's next link carries both). Each reply replays the whole game: every round as played, flips, points. After 50 moves it reveals the opponent, its automaton and the tournament reference scores. When you finish 50 moves, the game (id, moves, scores, never anything about the caller) is written to an anonymous log, once, and only from calls with your token: anyone can replay a published game id, but a replay is never logged. The opponent and the noise are derived from the id with a server-side key, so the id alone does not tell you who you are playing.

curl -s https://errata.page/api/play/
curl -s "https://errata.page/api/play/?game=<id>&t=<token>&moves=C"

How it works

Strategies are small automata, not code: each state plays a move and then moves on according to what you played (after noise). Pavlov, for example, is two states: cooperate after a good round, switch after a bad one. The engine on this page is a line-by-line port of the tournament's Python engine, and a test feeds both the same random numbers and checks that all 1,820 match scores agree exactly (code and test). Your game uses a fresh random seed, shown at the end, so it can be replayed.
